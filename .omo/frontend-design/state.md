# Frontend Design State

## Accepted debt

- **React audit tooling:** `react-grab` and `react-scan` are development-only dynamic imports, so their production bundle cost is **0 bytes**. They add developer-machine install time and lockfile surface area; `react-doctor` is a development-only static scanner. `npm run verify:no-devtools` and CI scan built JavaScript for all three identifiers to prevent a production leak.
- **`window.prompt` fallback in the Copy PGN path (DESIGN.md 8.7 D-04):** every user-facing state in the product now runs through the DESIGN.md 7.3 feedback primitives — there is no `window.alert` and no `window.confirm` anywhere in `web/src` — but one `window.prompt` survives in `web/src/panels/StudyPanel.tsx` as the last resort when `navigator.clipboard.writeText` rejects or is absent. It is kept because removing it would delete a working recovery path, and this plan forbids functional change. The failure is announced first through the assertive toast lane (`Couldn’t reach the clipboard — copy the PGN from the box that follows.`) and the prompt is deferred one frame so the live region commits before the synchronous modal blocks paint; `web/tests/feedback.spec.ts` asserts both the announcement and the surviving prompt. **Exit condition:** replace with a `DialogSurface` carrying a selectable read-only PGN field in a future functional change, then delete D-04.
